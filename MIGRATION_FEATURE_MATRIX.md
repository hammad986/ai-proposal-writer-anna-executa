# AI Proposal Writer — Migration Feature Matrix

This document tracks every core feature from the original Next.js application, its target destination in the Anna App architecture, migration strategy, current status, and verification test method.

| # | Feature | Original Implementation | Required in Anna? | Anna Destination | Migration Strategy | Status | Test Method |
|---|---|---|---|---|---|---|---|
| 1 | **Proposal Dashboard & Metrics** | `src/app/proposals/page.tsx` + `useProposalDashboard` | Yes | App UI (`bundle/src/views/DashboardView.tsx`) | Render KPI statistics (Total proposals, total INR value, accepted, pending) and table of proposals with status badges | In Progress | Render UI in harness; verify metric calculations with demo proposals |
| 2 | **4-Step Proposal Wizard** | `src/app/proposals/new/page.tsx` + `FormStep1..4` | Yes | App UI (`bundle/src/views/NewProposalView.tsx`) | Reusable React form components with live draft auto-save and per-step validation | In Progress | Step through Basics → Scope → Pricing → Style; verify field validation |
| 3 | **Live Draft Auto-Save** | Zustand `persist` in `localStorage` | Yes | App UI + `anna.storage` | Save draft state into `anna.storage` (`ai-proposal-writer:form_draft`) with local fallback | In Progress | Type into inputs, switch steps/reload, verify input retention |
| 4 | **AI Proposal Generation** | `POST /api/generate` via `@google/generative-ai` | Yes | Executa (`tool-dev-ai-proposal-writer-anna`) | Method `generate_proposal` called via `anna.tools.invoke`. Uses Anna LLM sampling reverse-RPC with structured JSON normalization | In Progress | Submit valid form; verify generated proposal contains title, dates, and all requested sections |
| 5 | **Generation Progress Overlay** | `components/proposal/generating-view.tsx` | Yes | App UI (`bundle/src/components/proposal/GeneratingView.tsx`) | Animated modal dialog with progress bar and staged status messages during Executa tool execution | In Progress | Trigger generation; observe progress steps and completion transition |
| 6 | **Proposal Document Viewer** | `components/proposal/proposal-viewer.tsx` | Yes | App UI (`bundle/src/views/ProposalDetailView.tsx`) | Interactive viewer with sticky table of contents navigation, metadata header, and structured section cards | In Progress | Open proposal; verify sidebar section anchors jump to correct section |
| 7 | **Structured Content Rendering** | `PricingTable`, `TimelinePhases`, `renderSectionContent` | Yes | App UI (`bundle/src/components/proposal/...`) | Markdown table parser, timeline phase cards, bullet lists, and bold text rendering | In Progress | Verify tabular formatting for Pricing and numbered cards for Timeline |
| 8 | **Inline Section Editing** | `components/proposal/section-card.tsx` | Yes | App UI (`bundle/src/components/proposal/SectionCard.tsx`) | Toggle text edit mode with Save / Cancel actions and visual "Edited" badge | In Progress | Edit section text, click Save; verify updated content and "Edited" badge |
| 9 | **Single-Section AI Regeneration** | `POST /api/generate` with `{ formData, section }` | Yes | Executa method `regenerate_section` | Invoke Executa with section context; update only the targeted section in proposal state | In Progress | Click regenerate on a single section; verify only that section updates while others remain unchanged |
| 10 | **PDF Export & Download** | `@react-pdf/renderer` via `PDFDownloadLink` | Yes | App UI (Client PDF engine + Print layout) | Self-contained, high-fidelity PDF generation producing standard formatted A4 document matching original styles | In Progress | Click "Download PDF"; verify PDF file downloads with complete proposal text |
| 11 | **Proposal Deletion** | Radix Alert Dialog in `ProposalsPage` | Yes | App UI (`DashboardView.tsx`) | Confirmation modal before removing proposal from store and persisting changes | In Progress | Click Delete icon, confirm in dialog; verify proposal removed from list and storage |
| 12 | **Window & Lifecycle Integration** | Browser `window` / Next.js layout | Yes | Anna Host API (`anna.window.*`) | Call `anna.window.set_title` and `anna.window.ready` on mount | In Progress | Verify window title reflects active view; no errors in console |
| 13 | **Security & Secret Protection** | Required `GEMINI_API_KEY` on server | Yes | Platform Anna sampling / Zero secrets | Eliminate all provider API keys from code and bundle. Rely on platform sampling | In Progress | Audit codebase; verify no keys or credentials exist in bundle |
| 14 | **Strict Manifest Validation** | None | Yes | `manifest.json` | Configure `schema: 2`, `required_executas`, `ui.bundle`, and minimal scoped `host_api` permissions | In Progress | Run `anna-app validate --strict` |
